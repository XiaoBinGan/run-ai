Nodes are worker machines in Kubernetes and may be either a virtual or a physical machine, depending on the cluster. 
Each Node is managed by the NVIDIA Run:ai control plane. For more information, see [Nodes](/run-ai/self-hosted/documentation/platform-management/manage-ai-initiatives/resources/nodes).
